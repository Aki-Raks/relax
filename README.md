# Расслабься ☕️

Мини-приложение для спонтанного отдыха и борьбы с муками выбора. Помогает определиться, чем заняться в свободную минуту, когда глаза разбегаются.

*Эта ветка адаптирована для работы в мобильной среде (Android) с сохранением данных в памяти устройства.*

## Возможности
- **Главное меню** — быстрый доступ ко всем разделам.
- **Выбор занятия** — случайный выбор дела из конкретной темы или абсолютный рандом по вообще всем доступным спискам («Вообще не понимаю что делать»).
- **Галерея тем** — наглядное отображение всех списков в виде Pinterest-сетки с живым поиском по названию и возможностью удаления.
- **Создание списков** — добавление новых тем и пунктов «на поделать» с динамическим управлением полями и строгой валидацией.
- **Редактирование** — изменение существующих тем и списков дел.

## Технологии
Проект написан на «чистом» стеке без использования тяжелых сторонних библиотек и фреймворков:
- **HTML5** (семантическая разметка)
- **CSS3** (Flexbox, кастомные стили, стеклянный морфизм `backdrop-filter`, адаптивный дизайн)
- **JavaScript (ES6+)** (DOM-манипуляции, асинхронность `async/await`, `localStorage`, `fetch API`)
- **JSON** (структурированные стартовые данные)

## Как устроено сохранение данных
В отличие от версий с ручным скачиванием файлов, здесь используется **`localStorage`**:
1. При самом первом запуске приложение считывает базовый набор из `data.json` и автоматически записывает его в память устройства.
2. Все последующие действия (создание новых списков, редактирование или удаление) мгновенно и незаметно обновляются в `localStorage`. Никаких файлов вручную переносить больше не нужно.

## Как запустить проект для разработки
Поскольку для первого чтения используется `fetch`, проект лучше открывать через локальный сервер:
1. Клонируй репозиторий и переключись на нужную ветку.
2. Открой папку с проектом в VS Code.
3. Запусти проект через расширение **Live Server** (правый клик по `index.html` -> *Open with Live Server*).

## Сборка под Android (через Capacitor)
Проект полностью готов к превращению в мобильное приложение:
1. Установи зависимости: `npm install`
2. Инициализируй и добавь Android-платформу: `npx cap add android`
3. Синхронизируй файлы: `npx cap copy`
4. Открой проект в Android Studio: `npx cap open android` и собери готовый `.apk`.
