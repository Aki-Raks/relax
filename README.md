# Имя проекта: Расслабься

Мини-приложение для тестов, спонтанного отдыха и борьбы с муками выбора. Помогает определиться, чем заняться в свободную минуту, когда глаза разбегаются.

---

## Возможности

* **Главное меню** — быстрый доступ ко всем разделам.
* **Выбор занятия** — случайный выбор дела из конкретной темы или абсолютный рандом по **вообще всем** доступным спискам («Вообще не понимаю что делать»).
* **Создание списков** — добавление новых тем и пунктов «на поделать» с динамическим управлением полями и строгой валидацией.
* **Редактирование** — изменение существующих тем и списков дел по их уникальному `id`.
- **Галерея тем** — наглядное отображение всех списков в виде Pinterest-сетки с живым поиском по названию и возможностью удаления.
* **Локальное хранение данных** — архитектура построена на работе с единым файлом `data.json` с поддержкой накопления и скачивания обновлений.

---

##  Технологии

Проект написан на «чистом» стеке без использования сторонних библиотек и фреймворков:
* **HTML5** (семантическая разметка)
* **CSS3** (Flexbox, кастомные стили, стеклянный морфизм `backdrop-filter`, адаптивность)
* **JavaScript (ES6+)** (DOM-манипуляции, асинхронность `async/await`, `fetch API`, работа с `Blob` и файловой загрузкой)
* **JSON** (структурированное хранение данных)

---

##  Как запустить проект

Поскольку проект работает с локальным файлом `data.json` через `fetch`, для корректной работы в браузере рекомендуется открывать его через локальный сервер.

1. Скачай или клонируй репозиторий на свой компьютер.
2. Открой папку с проектом в **VS Code**.
3. Установи расширение **Live Server** (если еще не установлено).
4. Нажми правой кнопкой мыши по файлу `index.html` и выбери **«Open with Live Server»**.
5. Готово! Приложение открыто в браузере и полностью готово к использованию.

---

##  Как устроено сохранение
При создании или редактировании списков приложение автоматически собирает актуальные данные, обновляет структуру (находя элементы по `id` или формируя новые порядковые номера) и скачивает свежий файл `data.json`. Тебе нужно просто заменить им старый файл в папке проекта.
